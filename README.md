# TravelHelperUtilities
Before flying home, a traveller wants two quick checks: roughly how much a yen amount is in Taka, and whether a checked bag is within the 23 kg limit. Neither check depends on any particular person, so no object is needed.
<br>
Topics Covered:
<br>

1. Class and Static Methods
2. @staticmethod decorator
3. Calling static methods using class name
4. User input with input()
5. Type conversion using float()
6. Conditional statements (if-else)
7. Returning values from methods
